## ✅ P2: Save Data Config (MEDIUM)

**File:** `src/libs/libSaveData.cpp`

### Changes:
- **Environment Variable**: `KYTY_SAVE_DATA_DIR` overrides default path
- **Launcher Integration**: Launcher can set save directory dynamically
- **Backward Compatible**: Defaults to `_SaveData` if not configured
- **All References Updated**: 4 locations now use `GetSaveDataDir()`

### Usage:
```bash
# Set via environment variable
set KYTY_SAVE_DATA_DIR=C:\Games\KytySaves

# Or let launcher configure it per-game
```

### Code:
```cpp
static std::string GetSaveDataDir() {
    const char* env_dir = std::getenv("KYTY_SAVE_DATA_DIR");
    if (env_dir != nullptr && env_dir[0] != '\0') {
        return std::string(env_dir);
    }
    return "_SaveData";  // Default
}
```

**Impact:** 💾 Enables proper save data management for GT7 career mode
