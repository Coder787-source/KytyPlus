KytyPlus

An experimental PS5 emulator for Windows.

Open-source, KytyPS5-based. Built for crash and boot-reach work — not a claim that games are playable.

View the KytyPlus Source Code on GitHub Releases

What this is

KytyPlus is a community emulator derived from KytyPS5. The focus is fewer hard crashes, clearer HLE gaps, and better reach on Windows + Vulkan — especially on integrated GPUs.

Source is public under GPL-2.0. Binary builds should always point back here. If a download does not link to this repository, treat it as unverified.
